# MPLADS AI Monitoring System — Frontend

A modern, responsive frontend for an **AI-powered MPLADS monitoring system** designed to help government officers monitor projects, identify risk alerts, analyze project data, and review implementation status.

---

## 📌 Project Overview

The MPLADS AI Monitoring System frontend provides a centralized interface for monitoring MPLADS projects through a professional, government-oriented dashboard.

The frontend includes:

- Central Monitoring Dashboard
- Risk Alerts
- Projects
- Analytics
- State Performance
- Site Monitoring
- AI Insights
- Reports
- Audit & Review
- Login & Signup

The interface uses a clean light theme, blue accents, responsive layouts, interactive maps, dashboard cards, charts, and monitoring components.

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Leaflet.js
- OpenStreetMap
- REST API Integration
